# BLP Visualizer

A command-line simulator for the Bell-LaPadula (BLP) confidentiality model, prepared for ITIS 3200 Lab 5.

## Files

- `Cases.py` defines and runs all 18 assignment scenarios.
- `BLP.py` implements subjects, objects, security levels, read/write checks, and state display.
- `Lab05-walkthrough.md` explains each case and provides written-answer drafts.

## Run

Open a terminal in this folder and run `python Cases.py`. Enter a case number from 1 to 18 to run that case, `A` to run all cases, or `Q` to quit.
